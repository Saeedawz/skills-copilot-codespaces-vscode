## Python Setup

This repository includes Python dependencies that can be installed using pip.

### Installation

To install the required Python packages, run:

```bash
pip3 install -r requirements.txt
```

Or from a specific directory:

```bash
pip3 install -r /path/to/repository/requirements.txt
```

### Requirements

- Python 3.12 or higher
- pip3

### Included Packages

- **Flask** - Web framework
- **Requests** - HTTP library
- **Pandas & NumPy** - Data analysis tools
- **Pytest** - Testing framework
- **Black & Flake8** - Code quality tools
- **Python-dotenv** - Environment variable management
