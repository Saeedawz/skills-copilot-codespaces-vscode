## My Calendar

A simple, interactive calendar application built with HTML, CSS, and JavaScript.

### Features
- 📅 Display current month and year
- 🔄 Navigate between months using arrow buttons
- ✨ Highlight the current day
- 📱 Responsive design
- 🎨 Beautiful gradient UI

### How to Open / Cara Membuka

**Method 1: Direct File Opening**
1. Locate the `index.html` file in this repository
2. Double-click the `index.html` file
3. It will open in your default web browser

**Method 2: Using a Web Browser**
1. Open your web browser (Chrome, Firefox, Safari, Edge, etc.)
2. Press `Ctrl+O` (Windows/Linux) or `Cmd+O` (Mac)
3. Navigate to this folder and select `index.html`
4. Click "Open"

**Method 3: In GitHub Codespaces/VS Code**
1. Right-click on `index.html`
2. Select "Open with Live Server" (if Live Server extension is installed)
   
   OR
   
3. Right-click on `index.html` and select "Open in Default Browser"

**Method 4: Using a Local Server**
```bash
# If you have Python installed
python -m http.server 8080
# Then open http://localhost:8080/index.html in your browser

# Or if you have Node.js with npx
npx http-server -p 8080
# Then open http://localhost:8080/index.html in your browser
```
