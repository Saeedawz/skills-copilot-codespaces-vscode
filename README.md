## My Calendar

A simple, interactive calendar application built with HTML, CSS, and JavaScript.

### Features
- 📅 Display current month and year
- 🔄 Navigate between months using arrow buttons
- ✨ Highlight the current day
- 📱 Responsive design
- 🎨 Beautiful gradient UI

### Usage
Simply open `index.html` in your web browser to view the calendar.

### Files
- `index.html` - Main HTML structure
- `style.css` - Styling and layout
- `calendar.js` - Calendar functionality and logic
