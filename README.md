# Wedding Invitation Creator ✨

A beautiful, customizable digital wedding invitation website where you can design your perfect wedding invitation.

## Features

- **Fully Customizable**: Personalize bride and groom names, wedding date and time, venue details
- **Multiple Themes**: Choose from 4 elegant invitation styles:
  - Classic Elegant
  - Modern Minimal
  - Romantic Floral
  - Rustic Charm
- **Color Customization**: Select from 6 beautiful theme colors
- **Personal Touch**: Add a custom message to your invitation
- **Live Preview**: See changes in real-time as you customize
- **Print/Download**: Download or print your customized invitation
- **Responsive Design**: Works beautifully on desktop, tablet, and mobile devices

## How to Use

1. Open `index.html` in your web browser
2. Fill in your wedding details in the customization panel:
   - Enter the bride's and groom's names
   - Select your wedding date and time
   - Add venue name and address
   - Choose your preferred theme color
   - Select an invitation style
   - Add a personal message (optional)
3. Watch the preview update in real-time on the right
4. Click "Download Invitation" to print or save your invitation
5. Use "Reset" button to restore default values

## Files

- `index.html` - Main HTML structure
- `styles.css` - Beautiful styling and responsive design
- `script.js` - Interactive customization functionality

## Technologies Used

- HTML5
- CSS3 (with responsive design and print styles)
- Vanilla JavaScript (no dependencies required)
